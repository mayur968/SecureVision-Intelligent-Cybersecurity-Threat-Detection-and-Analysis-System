================================================================================
SECUREVISION - QUICK SETUP GUIDE
Phase 1 (30%) Implementation
================================================================================

STEP-BY-STEP SETUP INSTRUCTIONS:

1. CREATE VIRTUAL ENVIRONMENT
   ----------------------------
   Windows PowerShell:
   
   python -m venv venv
   venv\Scripts\activate
   
   You should see (venv) in your command prompt.

2. INSTALL DEPENDENCIES
   --------------------
   pip install -r requirements.txt
   
   This will install Flask, scikit-learn, pandas, and other dependencies.
   
   Note: If androguard fails to install, that's okay - the system will work
   with basic APK analysis.

3. TRAIN THE MACHINE LEARNING MODELS
   ----------------------------------
   Run these commands in order:
   
   python training/train_url_model.py
   python training/train_message_model.py
   python training/train_apk_model.py
   
   Each script will:
   - Load sample data
   - Extract features
   - Train models
   - Save the best model
   - Display performance metrics
   
   Expected output: Accuracy, Precision, Recall, F1-score for each model

4. START THE APPLICATION
   ----------------------
   python app.py
   
   You should see:
   * Running on http://127.0.0.1:5000
   
   Open your web browser and navigate to:
   http://localhost:5000

5. TEST THE APPLICATION
   ---------------------
   a) Dashboard: View statistics and charts
   b) URL Scanner: Test with sample URLs:
      - Safe: https://www.google.com
      - Phishing: http://secure-login-verify.com/account
   
   c) Message Scanner: Test with sample messages:
      - Safe: "Hello, how are you doing today?"
      - Phishing: "URGENT: Your account has been suspended. Verify immediately."
   
   d) APK Scanner: Upload any .apk file (or create a dummy .zip and rename to .apk)
   
   e) History: View all scan results

6. RUN TESTS (OPTIONAL)
   ---------------------
   pytest tests/ -v

================================================================================
TROUBLESHOOTING:
================================================================================

PROBLEM: "No module named 'flask'"
SOLUTION: Make sure virtual environment is activated and dependencies installed

PROBLEM: "Model not found" error
SOLUTION: Run the training scripts (Step 3)

PROBLEM: "Port 5000 already in use"
SOLUTION: Either stop other application using port 5000, or change port in app.py

PROBLEM: Androguard installation fails
SOLUTION: This is optional. System will work with basic APK analysis.
