## Root Cause Summary

- The `/history` page fetches scan history data successfully from the backend (no failed requests).
- The `<History>` component at `src/pages/History.tsx:45` renders a table and passes each row's risk level to `<RiskBadge>`.
- `<RiskBadge>` at `src/components/ui/RiskBadge.tsx:34` dereferences `.cls` on a value that is `undefined` — crashing every row.
- React retries rendering (resulting in 4 identical errors) before giving up.
- The page crash (`TypeError: Cannot read properties of undefined (reading 'cls')`) blanks the table entirely — `tableRowCount` stays 0.

**Fix target:** `src/components/ui/RiskBadge.tsx` — add a guard for `undefined`/missing input, or align the expected prop shape with what the History API actually returns.
